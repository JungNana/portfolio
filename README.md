# Portfolio

Personal portfolio site, published with GitHub Pages.

Live site: https://jungnana.github.io/portfolio/

## Structure

- `index.html` – page content
- `style.css` – styles
- `.nojekyll` – tells GitHub Pages to serve files as-is

## Editing

Edit `index.html` and `style.css`, then commit and push to `main`. GitHub Pages redeploys automatically.
